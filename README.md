# ربات قیمت لحظه‌ای برای ایتا، بله و تلگرام

## برنامه‌ی انتشار (به وقت تهران)

| چه چیزی | کی | کجا |
|---|---|---|
| پیام پین‌شده‌ی زنده (ویرایش می‌شود، پست جدید نمی‌سازد) | هر ۱۰ دقیقه | تلگرام و بله |
| پست جدید قیمت‌ها | هر ساعت؛ از ۰ تا ۸ صبح فقط ساعت ۰، ۳ و ۶ و بی‌صدا | همه |
| کارت تصویری قیمت‌ها (به‌جای پست متنی) | ساعت ۱۰، ۱۴، ۱۸ و ۲۲ | همه |
| خلاصه‌ی روز: بیشترین رشد و افت، کف و سقف | ساعت ۲۰ | همه |
| نمودار هفتگی طلا و دلار | جمعه ساعت ۱۲ | همه |
| هشدار نوسان شدید | هر وقت دلار یا طلا در یک ساعت بیش از ۱٪ جابه‌جا شود | همه |

ایتایار متد ویرایش پیام ندارد، پس در ایتا پیام زنده نداریم و به‌جایش پست ساعتی پین می‌شود.
اگر ویرایش در بله یا تلگرام کار نکند، ربات خودکار همین رفتار را برای آن کانال در پیش می‌گیرد.
ربات باید در تلگرام و بله دسترسی «پین/ویرایش پیام» در کانال داشته باشد.

همه‌ی این ساعت‌ها با Variables مخزن قابل تغییرند (فهرست در `.env.example`).

## وضعیت ماندگار

ربات شناسه‌ی پیام پین‌شده، قیمت‌های امروز (برای خلاصه و هشدار) و قیمت ساعتی هفته‌ی اخیر (برای نمودار)
را در `state.json` نگه می‌دارد. در گیت‌هاب اکشنز این فایل روی شاخه‌ی `bot-state` همین مخزن ذخیره می‌شود؛
آن شاخه را پاک نکنید (اگر پاک شود، ربات یک پیام پین‌شده‌ی تازه می‌سازد و نمودار از صفر شروع می‌شود).

## منابع قیمت

| قلم | منبع اصلی | پشتیبان |
|---|---|---|
| دلار آزاد، طلا ۱۸، سکه، نقره، نفت برنت | tgju.org | — |
| انس طلا و انس نقره | tgju.org | gold-api.com |
| تتر (تومان) | نوبیتکس | tgju.org |
| بیت‌کوین و اتریوم (دلار) | نوبیتکس | CoinGecko، tgju.org |

اگر یک منبع قطع باشد، ربات خودکار سراغ منبع بعدی می‌رود و اگر قیمتی پیدا نشود فقط همان خط از پست حذف می‌شود.

## ۱. گرفتن توکن بله

1. در بله به ربات **@BotFather** پیام دهید و دستور `/newbot` را بزنید، نام و آیدی ربات را بدهید.
2. توکنی که می‌دهد را در `BALE_TOKEN` بگذارید.
3. در کانال بله: تنظیمات کانال ← مدیران ← افزودن مدیر ← ربات‌تان را با دسترسی «ارسال پیام» اضافه کنید.
4. در `BALE_CHAT_ID` آیدی کانال را با @ بنویسید (مثلاً `@gheymat_online`).

## ۲. گرفتن توکن ایتا (ایتایار)

ایتا ربات عمومی ندارد و ارسال خودکار از طریق سرویس رسمی **ایتایار** انجام می‌شود.
1. وارد [eitaayar.ir](https://eitaayar.ir) شوید و با شماره‌ی ایتای خود ثبت‌نام کنید.
2. در پنل، کانال‌تان را اضافه کنید و طبق راهنمای سایت حساب ایتایار را مدیر کانال کنید.
3. توکن API را از پنل کپی کنید و در `EITAA_TOKEN` بگذارید.
4. در `EITAA_CHAT_ID` آیدی کانال (بدون @) یا شناسه‌ی عددی‌ای که پنل نشان می‌دهد را بنویسید.

> ایتایار ممکن است برای تعداد پیام بالا اشتراک پولی بخواهد؛ با فاصله‌ی ۱۰ دقیقه حدود ۱۴۴ پست در روز می‌شود. اگر محدودیت داشتید فاصله را بیشتر کنید یا `QUIET_HOURS` را تنظیم کنید.

## ۲.۵ تلگرام (اختیاری)

1. در تلگرام به **@BotFather** پیام دهید، `/newbot` بزنید و توکن را در `TELEGRAM_TOKEN` بگذارید.
2. ربات را مدیر کانال تلگرام با دسترسی «Post messages» کنید.
3. در `TELEGRAM_CHAT_ID` آیدی کانال را با @ بنویسید.

## ۳. تنظیمات

فایل `.env.example` را به `.env` کپی کنید و پر کنید:

- `INTERVAL_MINUTES`: هر چند دقیقه یک پست (پیش‌فرض ۱۰). پست‌ها سر دقیقه‌های رُند می‌روند (۱۰:۰۰، ۱۰:۱۰، …).
- `QUIET_HOURS`: ساعت‌هایی که پست نشود، به وقت تهران. مثلاً `0-7`.
- `ITEMS`: کدام اقلام و به چه ترتیبی. مثلاً فقط `usd,usdt,gold18,coin`.
- `HEADER` و `FOOTER`: سرتیتر و پانویس پست.

## ۴. اجرا

```bash
pip install -r requirements.txt
cp .env.example .env      # و پر کردن آن
python bot.py --check     # ببینید منابع جواب می‌دهند
python bot.py --dry-run   # متن پست را ببینید (ارسال نمی‌شود)
python bot.py --once      # یک پست واقعی برای تست
python bot.py             # اجرای دائمی
```

### اجرای دائمی روی سرور لینوکس (systemd)

```bash
sudo mkdir -p /opt/price-bot && sudo cp -r ./* .env /opt/price-bot/
sudo cp /opt/price-bot/price-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now price-bot
journalctl -u price-bot -f        # دیدن لاگ‌ها
```

## کدام سرور؟

**سرور مجازی ایرانی پیشنهاد می‌شود.** نوبیتکس و ایتایار معمولاً به آی‌پی خارجی جواب نمی‌دهند، و tgju و بله از داخل ایران پایدارتر هستند. روی سرور ایرانی ممکن است gold-api و CoinGecko باز نشوند، که اشکالی ندارد چون فقط پشتیبان هستند.

## عیب‌یابی

- اگر خطی از پست جا افتاد، `python bot.py --check` را اجرا کنید و ببینید کلید مربوط در خروجی هست یا نه. tgju گاهی نام کلیدها را عوض می‌کند؛ نام درست را در `CATALOG` داخل `bot.py` (بخش `src`) جایگزین کنید.
- خطای `Bale: {... 'ok': False ...}` یعنی ربات مدیر کانال نیست یا آیدی کانال اشتباه است.

## اجرای رایگان با گیت‌هاب اکشنز (بدون سرور)

فایل `.github/workflows/post-prices.yml` ربات را روی سرورهای رایگان گیت‌هاب اجرا می‌کند. هر اجرا حدود ۵ ساعت و نیم
روشن می‌ماند و هر ۱۰ دقیقه یک دور کار می‌کند؛ اجرای بعدی از قبل در صف است و بلافاصله ادامه می‌دهد.
(زمان‌بندی cron خود گیت‌هاب برای فاصله‌های کوتاه قابل اعتماد نیست و اجراها را تا یک ساعت عقب می‌اندازد.)
اگر کد را عوض کردید، اجرای در حال کار را از تب Actions لغو کنید تا اجرای بعدی با کد تازه شروع شود.

1. در گیت‌هاب یک مخزن **Public** بسازید (برای مخزن عمومی دقیقه‌های اکشنز نامحدود و رایگان است؛ توکن‌ها در Secrets مخفی می‌مانند و دیده نمی‌شوند).
2. همه‌ی فایل‌های این پوشه، از جمله پوشه‌ی `.github`، را در مخزن آپلود کنید. فایل `.env` را آپلود **نکنید**.
3. در مخزن: Settings ← Secrets and variables ← Actions ← New repository secret، و این چهار مورد را بسازید:
   `BALE_TOKEN`، `BALE_CHAT_ID`، `EITAA_TOKEN`، `EITAA_CHAT_ID`
4. (اختیاری) در تب Variables همان صفحه: `FOOTER`، `HEADER`، `ITEMS`، `QUIET_HOURS`.
5. تب Actions ← Post prices ← Run workflow برای تست. اگر پست در کانال آمد، از این به بعد خودکار اجرا می‌شود.

محدودیت‌ها:
- زمان‌بندی گیت‌هاب دقیق نیست و پست‌ها ممکن است چند دقیقه (گاهی بیشتر) دیر برسند.
- سرورهای گیت‌هاب خارج از ایران‌اند، پس نوبیتکس استفاده نمی‌شود و تتر از tgju و بیت‌کوین/اتریوم از CoinGecko گرفته می‌شود.
- اگر مخزن ۶۰ روز هیچ تغییری نداشته باشد، گیت‌هاب زمان‌بندی را خاموش می‌کند و باید از تب Actions دوباره فعالش کنید.
